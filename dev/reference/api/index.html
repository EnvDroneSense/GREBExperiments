API Reference

GREBExperiments — Module
GREBExperiments

Tools for experiments with GREBClimate.jl. The package runs sets of model members, reduces each result to a few numbers (annual and area-weighted means, the Gregory sensitivity estimate, map diagnostics) and writes the rows to files. The scripts in scripts/ use these tools.

source

Maps

GREBExperiments.area_mean — Function
area_mean(map, mask=nothing)

Return the area-weighted mean of a (xdim, ydim) map. With a Bool mask, the mean is over the cells where mask is true. A mask of numbers is a weight.

A map or mask of the wrong size throws a DimensionMismatch, so a transposed map does not pass silently. A mask that selects no cell throws an ArgumentError.

source
GREBExperiments.zonal_mean — Function
zonal_mean(map)

Return the mean over longitude of a (xdim, ydim) map: one value per latitude row.

source
GREBExperiments.polar_amplification — Function
polar_amplification(map; latitude=60)

Return (north, south, north_mean, south_mean, global_mean). north_mean and south_mean are the area-weighted means of map poleward of latitude degrees in each hemisphere. north and south are these means divided by global_mean. A uniform map gives north = south = 1.0.

Give a change, not an absolute temperature: the cold poles give a ratio below 1 for any absolute map. When the global mean is near zero (a regional or residual map), the ratio is very large or changes sign. Use the means then.

source
GREBExperiments.land_ocean — Function
land_ocean(map, z_topo)

Return (land, ocean): the area-weighted means of map over the land cells and over the ocean cells. The topography z_topo of the climatology sets which cells are land.

source
GREBExperiments.pattern_correlation — Function
pattern_correlation(a, b)

Return the area-weighted correlation of two maps, about their own weighted means. A positive scale factor or a shift of a map does not change it. A constant map has no pattern and throws an ArgumentError.

Series

GREBExperiments.annual_means — Function
annual_means(records, times, f)

Return (years, values, dropped). For each year that has all 12 months in records, values holds the annual mean of f(record). dropped lists the years with fewer than 12 months, so a partial year does not look like a full one.

f is a field name, such as :Ts, for the area-weighted global mean of that field. It can also be a function of one record that returns a number. times holds the (year, month) of each record. A (year, month) that occurs twice, as in two joined runs, throws an ArgumentError.

All months have the same weight. To change this, give month_weights (12 values, for example the days per month). This has no effect on a constant and a small effect on an anomaly.

GREBExperiments.sine_fit — Function
sine_fit(series, period)

Fit c + a sin(2 pi t / period) + b cos(2 pi t / period) to series by least squares, with t in samples from 0. Return (amplitude, lag, mean):

FieldContent
amplitudehypot(a, b), in the unit of the series
lagIn samples; positive when the series peaks later than sin. It is wrapped to (-period/2, period/2]: a true lag of 0.6 periods gives -0.4 periods
meanc

The fit has no trend term, so give a whole number of periods. A series shorter than one period throws an ArgumentError.

GREBExperiments.gregory — Function
gregory(dTs, dnet)

Fit dnet = forcing + feedback * dTs by least squares and return the Gregory estimate. dTs [K] and dnet [W/m2] are annual global means of the change in surface temperature and in top-of-atmosphere net flux. An example is the Ts and net series of the scenario in summarize of an abrupt-CO2 run.

FieldContent
forcingThe fit at zero warming [W/m2]
feedbackThe slope of the fit [W/m2/K]; negative for a stable climate
sensitivity-forcing / feedback [K]: the warming at which the fit reaches zero net flux
r2The coefficient of determination of the fit
reached, remainingThe last dTs and the last dnet
closurereached / sensitivity

closure can differ from 1 even near equilibrium, because sw - olr is not the full budget of the anomaly. Two more flows change with the warming: the latent heat of the open water budget (evaporation and rain do not balance) and the heat sink of the transport. In an abrupt 2xCO2 run, they make the sensitivity approximately 10 percent lower than the warming that the run reaches.

Each series needs at least three values. A constant dTs throws an ArgumentError. When feedback >= 0, the fitted line has no stable equilibrium: sensitivity and closure are NaN, and the function logs a warning.

Reducing a result

GREBExperiments.in_range_report — Function
in_range_report(records, times, anomaly; anomaly_limits=ANOMALY_LIMITS)

Return nothing when all values of Ts, Ta, To and q in records are finite and in the allowed range. Otherwise return (year, month, field, value) of the first value that is not. times holds the (year, month) of each record.

For absolute records (anomaly=false), the range is that of GREBClimate.RangeCheck(). For anomalies, the size of a value must not exceed the entry of its field in anomaly_limits: by default 80 K for Ts and Ta, 40 K for To and 0.08 kg/kg for q.

The records are monthly means, so the function does not see a short excursion inside a month. It does not test the other fields. For a member that can diverge, also give GREBClimate.RangeCheck() as the observer of greb_model!.

GREBExperiments.summarize — Function
summarize(result)

Reduce a greb_model! result to a few kilobytes and return a NamedTuple:

FieldContent
ctrl, scnr(years, Ts, precip, ice, net): the complete years and the annual global means. ice is the ice fraction (0 to 1). net is the top-of-atmosphere net flux sw - olr
scnr_anomalytrue when the scenario records are anomalies from the control
driftThe change of the annual Ts of the control from its first to its last year [K]; NaN for one year. A control in equilibrium has no drift
out_of_range(ctrl, scnr): for each phase, nothing or the first record out of range (see in_range_report)

The function tests the control and the scenario separately, because a scenario can leave the range while its control stays in range.

Files and running members

GREBExperiments.co2_file — Function
co2_file(path, years, values)

Write a CO2 path as a text file of year ppm lines and return path. CO2File(path) and load_co2_custom read this file.

years and values must have the same length. Each year must occur only once. Each value [ppm] must be finite and positive. The file holds the values at Float32 precision, because the model reads them at that precision.

source
GREBExperiments.run_members — Function
run_members(reduce, run, configs; labels, outdir=nothing, name="members",
            fields, jld2_dir="", ntasks=Threads.nthreads(), kwargs...)

Run each member of configs with run (a RunSpec) through GREBClimate.run_ensemble and return one row per member. A row is labels[i] merged with reduce(result). Both are NamedTuples of scalars: the labels identify the member, and reduce gives the numbers to keep. reduce runs in the task of the member, so only these numbers stay in memory.

With outdir, the function also writes outdir/<name>.csv (one line per row, NaN as NaN) and outdir/<name>_manifest.toml. The manifest holds the package versions, the run lengths, the column names, the configuration of each member and the time. The other keyword arguments go to run_ensemble.

labels must have one entry per member, or the function throws a DimensionMismatch. All members must give the same column names, or the function throws an ArgumentError before it writes a file.

write_members(outdir, name, rows, run, configs)

Plots

GREBExperiments.plot_response — Function
plot_response(rows; x=:co2_ppm, y=:Ts_anom_K, xlog=false)

Plot column y against column x of rows and return the plot. rows is a vector of NamedTuples, as run_members returns. xlog=true puts x on a log axis, for example for CO2. Run using Plots first.

source
GREBExperiments.plot_gregory — Function
plot_gregory(dTs, dnet)

Plot the annual net-flux change dnet [W/m2] against the warming dTs [K] and return the plot. The plot also shows the line that gregory fits and the point where the line crosses zero, the effective sensitivity. Run using Plots first.
